# HCare

Веб-приложения для пациентов и докторов для просмотра персональной информации, хранения списка активностей и предоставление обратной связи

## Функциональность

Приложение предоставляет следующие возможности:

* Навигацию по страницам
* Изменение и добавление информации о пациенте
* Персанолизированные настройки
* Просмотр списка действующих докторов
* Бронирование записи к доктору
* Фильтрация докторов
* Предоставление обратной связи

## Технологии

* React
* React Router
* Redux Toolkit
* RTK Query
* JavaScript
* CSS

## Зависимости

Основные зависимости проекта:

* `react` - библиотека для создания пользовательского интерфейса
* `react-dom` - работа React с DOM
* `react-router-dom` - маршрутизация приложения
* `@reduxjs/toolkit` - управление состоянием и работа с API
* `react-redux` - интеграция Redux с React
* `react-toastify: ^11.1.0`: - показ всплывающих тостов

## Установка

Клонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейти в директорию проекта:

```bash
cd <название-проекта>
```

Установить зависимости:

```bash
npm install
```

## Запуск

Для запуска проекта в режиме разработки:

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```

## Сборка проекта

Для создания production-сборки:

```bash
npm run build
```
